# Product Sense

## What This Project Is

This project is a standalone MCP server that gives MCP clients a validated operational surface for ClickUp.

Its value is not “many tools.”
Its value is “trustworthy tools.”

## Product Standard

A tool is only product-ready when:

- the contract is documented
- the route and payload shape are validated
- failure behavior is understood
- the docs reflect actual behavior

## Product Constraint

Feature count is not a success metric until trust is rebuilt.
