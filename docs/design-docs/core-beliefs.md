# Core Beliefs

## Belief 1

Correctness matters more than breadth.

## Belief 2

Documented behaviour must be earned through validation.

## Belief 3

Composition over validated primitives is better than relying on undocumented bulk endpoints.

## Belief 4

A tool contract is part of the product, not just a manifest file.

## Belief 5

A public repository should make the state of trust obvious to a new reader.
